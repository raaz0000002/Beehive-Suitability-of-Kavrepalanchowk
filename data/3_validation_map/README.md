# 3. Validation Maps and Logs

This directory contains the final maps and tabular validation tables:
- **`Beehive_Suitability_5Class_FINAL.png`**: The final export map with validation markers and labels.
- **`Beehive_Suitability_5Class_FINAL.tif`**: The final georeferenced GeoTIFF (nodata=0 for ArcGIS/QGIS compliance).
- **`Beehive_Validation_Points_All_Extracted_Suitability.csv`**: Extract of suitability score classes for all 10 ground-truth bee locations.
- **`Beehive_Validation_Points_VISIBLE_Map_Numbering.csv`**: CSV detailing the coordinates, place names, and sequential display numbers of the unique visible points plotted on the map.
